This project is a port of the Cells2Pixels growing demo to the jax-js machine learning framework, based on the Neural Cellular Automata research by Pajouheshgar et al. presented at SIGGRAPH '26. It demonstrates the implementation of high-performance WebAssembly and WebGPU kernels within a pure JavaScript environment.
