Gameslop is a manifesto for rapidly developing games in 2026 using vanilla web technologies like HTML, DOM, and Canvas2D. It advocates for using AI tools like Composer 2, Cursor, or Gemini to generate code for simple 2D games, while utilizing techniques such as Position-Based Dynamics, noise, and raymarching to enhance game mechanics and visuals.
