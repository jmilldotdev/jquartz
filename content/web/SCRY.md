Scry is an infinite precision internet search tool that provides a read-only SQL API over tens of terabytes of public text and metadata. It allows agents to run inspectable queries across papers, forums, social archives, government records, and markets while offering typed and vector search over provenance-bearing public corpora with source-level coverage accounting.
