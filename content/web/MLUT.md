mlut is a Tailwind CSS alternative designed for custom websites and creative coding that uses short, consistent naming conventions based on CSS property popularity. It features a native syntax conceptually close to CSS, is written in Sass, and allows developers to create complex styles, states, and at-rules using utility classes.
